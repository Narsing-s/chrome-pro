# Code of Conduct

Chrome Pro is a community project. Participants are expected to be respectful, constructive, and welcoming.

## Expected behavior

- Discuss ideas, code, and evidence rather than people.
- Welcome different experience levels.
- Give actionable feedback.
- Respect privacy and confidentiality.
- Keep technical discussions focused and professional.

Harassment, discrimination, threats, doxxing, deliberate disruption, and other abusive behavior are not acceptable.

Project maintainers may moderate issues, pull requests, and discussions when necessary to keep the project healthy.
